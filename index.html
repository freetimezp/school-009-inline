01   THE IDEA

Good alignment
creates clarity.

Think about buttons, navigation links, notifications and labels. They often combine an icon with text. When these elements don't align properly, even a beautiful interface can feel unfinished.

We'll explore how inline formatting works and how Flexbox gives us precise control over positioning, spacing and responsive layouts.

IN THIS LESSON 01 Inline elements 02 Text baseline 03 Vertical align 04 Flexbox basics 05 Align items 06 Gap and spacing 07 Flex sizing 08 Responsive layout 09 SVG icons 10 Mini project
01 / HTML INLINE ELEMENTS

Elements that share a line.

Inline elements participate in the current text line. They usually take only the space their content needs instead of starting a new line.

INLINE EXAMPLE

Read our latest article ↗ for more information.

HTML 
<p>
    Read our
    <a href="#">latest article</a>
    <span>↗</span>
    for more information.
</p>
✳

Remember: Inline elements flow naturally with surrounding text. Their alignment is influenced by the text line and font metrics.

02 / TYPOGRAPHY THE BASELINE

Why does an icon look too low?

Text characters sit on an invisible baseline. Inline icons can align to that baseline too, which sometimes makes an icon appear slightly lower than the center of the text.

DEFAULT BASELINE

Message ✦

VISUALLY CENTERED

Message ✦

CSS 
.icon {
    vertical-align: middle;
}
✳

Key idea: Text baseline and visual center are not the same thing. This is why an icon can look slightly misaligned.

03 / CSS VERTICAL-ALIGN

Adjust an inline element.

The vertical-align property controls how an inline-level element aligns relative to the surrounding text line.

BASELINE

Text ✦

MIDDLE

Text ✦

SUPER

CSS 
.icon {
    vertical-align: middle;
}

/* Other values */
.icon {
    vertical-align: baseline;
    vertical-align: super;
    vertical-align: sub;
}
04 / CSS DISPLAY FLEX

Meet Flexbox.

Flexbox creates a flexible layout container. Its direct children become flex items, which can be aligned and spaced along two axes.

ICON
TEXT
BADGE
CSS 
.container {
    display: flex;
}
✳

Remember: Flexbox affects the direct children of the flex container. Nested elements need their own layout rules.

05 / FLEXBOX ALIGN-ITEMS

Bring everything to the center.

The align-items property controls alignment on the cross axis. In a row layout, this is usually the vertical axis.

FLEX-START
CENTER
FLEX-END
CSS 
.container {
    display: flex;
    align-items: center;
}
06 / FLEXBOX GAP AND SPACING

Space without extra margins.

The gap property creates consistent spacing between flex items. It is often simpler than adding margins to individual children.

ICONTEXT
ICONTEXT
CSS 
.container {
    display: flex;
    align-items: center;
    gap: 12px;
}
07 / FLEXBOX FLEX-SHRINK

What happens when space gets tight?

Flex items can shrink when there isn't enough room. The flex-shrink property controls how much an item is allowed to shrink.

ICON
This text area has room to adapt to the available width.
NEW
CSS 
.icon,
.badge {
    flex-shrink: 0;
}

.text {
    flex: 1;
    min-width: 0;
}
✳

Practical tip: Use flex-shrink: 0 for icons that should retain their size when the text becomes longer.

08 / RESPONSIVE FLEX-WRAP

Let the layout breathe.

When items no longer fit in one row, flex-wrap allows them to move onto another line instead of overflowing.

DESIGN DEVELOPMENT ANIMATION INTERACTION
CSS 
.tags {
    display: flex;
    flex-wrap: wrap;
    gap: 10px;
}
09 / HTML SVG ICONS

Use icons that scale cleanly.

SVG icons are vector graphics. They remain sharp at different sizes and can be styled with CSS. Give decorative icons aria-hidden="true" and make sure meaningful icons have an accessible name.

Explore the project
HTML 
<span class="link-icon">
    <svg
        viewBox="0 0 24 24"
        aria-hidden="true"
    >
        <path d="M7 17 17 7" />
        <path d="M7 7h10v10" />
    </svg>
</span>
